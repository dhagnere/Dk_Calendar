# ⚡ Conversion Excel → CSV (30 secondes)

## 🎯 Objectif
Convertir `special_events_global.xlsx` en CSV pour éviter les timeouts

---

## 📝 Procédure (4 étapes)

### 1️⃣ Ouvrir le fichier
- Double-cliquez sur `special_events_global.xlsx`
- Le fichier s'ouvre dans Excel

### 2️⃣ Enregistrer sous
- **Fichier** → **Enregistrer sous**
- Ou **Ctrl+Maj+S** (Windows) / **Cmd+Maj+S** (Mac)

### 3️⃣ Choisir le format CSV
- **Type** → Sélectionnez **"CSV (délimiteur : point-virgule) (*.csv)"**
- ⚠️ **PAS** "CSV UTF-8" ni "CSV (virgule)"
- Conservez le même nom : `special_events_global.csv`

### 4️⃣ Enregistrer
- Cliquez sur **Enregistrer**
- Si Excel demande confirmation → cliquez **Oui**

---

## ✅ C'est fait !

Vous avez maintenant :
- ✅ `special_events_global.xlsx` (original, gardez-le)
- ✅ `special_events_global.csv` (pour l'import)

---

## 🚀 Import
1. Retournez dans l'application
2. Sélectionnez le fichier `.csv`
3. Cliquez sur **Importer**

**⏱️ Temps estimé : ~2-3 minutes pour 528 lignes** ✅

---

## 🔍 Vérification rapide

Faites un clic droit sur le fichier CSV et ouvrez-le avec **Bloc-notes** ou **TextEdit**.

**Bon format :**
```
Date;Date de début;Date de fin;Nom;Lieu;...
2026-08-12;2026-02-06;2026-08-31;HABITER LA MODERNITÉ...
```

Si vous voyez des **points-virgules (;)** entre les colonnes → ✅ C'est bon !  
Si vous voyez des **virgules (,)** → ❌ Recommencez et choisissez "CSV (délimiteur : point-virgule)"
